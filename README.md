🚀 Smart Internship Matchmaker
AI-Powered Resume-Based Internship & Job Matching Platform

Smart Internship Matchmaker is an AI-driven web application that automatically analyzes a candidate’s resume and intelligently matches them with the most relevant internships and job opportunities based on skills, qualifications, location, and preferences.

Built using Streamlit, this platform simplifies the internship discovery process and ensures better alignment between candidates and opportunities.

📌 Problem Statement

Students often struggle to:

Identify internships relevant to their skills

Understand eligibility requirements

Manually search and apply across multiple platforms

Receive clear explanations for why a role is suitable

This leads to missed opportunities, wasted effort, and poor career decisions.

💡 Solution

Smart Internship Matchmaker solves this by:

Automatically extracting information from resumes

Analyzing skills, education, and experience

Matching candidates to suitable internships/jobs using AI

Providing match scores and transparent explanations

The platform ensures data-driven, unbiased, and personalized recommendations.

🧠 Key Features
📄 Resume Upload & Parsing

Upload resume in PDF format

AI extracts:

Skills

Education

Experience

Qualifications

Eliminates manual form filling

🤖 AI-Based Matching Engine

Matches candidates with internships/jobs using:

Skill similarity

Qualification alignment

Location preferences

Generates match percentage scores

📊 Match Breakdown & Explainability

Transparent AI analysis showing:

Skills match

Location match

Qualification match

Helps candidates understand why a role fits them

📈 Analytics Dashboard

Candidate demographics analysis

Company and internship distribution by industry

Useful for administrators and policymakers

🧭 Simple & Intuitive UI

Built with Streamlit

Easy navigation:

Register as Candidate

Upload Resume

Find Matches

View Applications

Analytics Dashboard

🛠️ Tech Stack

Frontend & App Framework: Streamlit

Backend Logic: Python

Resume Parsing: NLP-based text extraction

AI Matching: Skill similarity & rule-based scoring

Data Handling: Pandas, NumPy

Visualization: Streamlit charts & analytics

⚙️ How It Works (Workflow)

Candidate uploads resume (PDF)

AI extracts text from the resume

Skills, education, and qualifications are identified

Matching algorithm compares candidate profile with internship/job requirements

Match scores and explanations are generated

Best-fit internships/jobs are displayed
